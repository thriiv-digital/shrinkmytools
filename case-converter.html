About Case Conventions

Different contexts expect different text casing — here's what each one is typically used for:

  • camelCase — variable and function names in JavaScript, Java, and most C-style languages, e.g. firstName
  • PascalCase — class and component names, e.g. UserProfile
  • snake_case — variable names in Python and Ruby, and database column names, e.g. first_name
  • kebab-case — URL slugs, CSS class names, and file names, e.g. user-profile
  • CONSTANT_CASE — constants and environment variables, e.g. MAX_RETRIES
  • Title Case — headings and titles, e.g. "The Quick Brown Fox"
  • Sentence case — standard prose, e.g. "The quick brown fox"
